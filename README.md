# 📘 Smart Notebook Pro

## 🌍 Multi-Language Smart Planner with Advanced Features

**Supported languages:** Arabic, English, French, Russian, Spanish, Chinese, Persian (فارسی)

## ✨ Features
- 📅 Monthly & Daily task organization
- ✅ Add, complete, delete tasks
- 🏷️ Click on any category to add a task (no separate input bar)
- ⏰ Time scheduling with notifications
- 🔁 Recurring tasks (daily, weekly, monthly)
- 📊 Dashboard with statistics
- 🔍 Search tasks
- 📤 Export / Import backup (JSON)
- 🌙 Dark mode (saved)
- 🌐 7 languages UI
- 📱 PWA installable & offline ready

## 🚀 How to use
1. Open `index.html` in any modern browser.
2. Select a month, then a day.
3. Click on a category button (Study, Shopping, etc.) to open a modal dialog.
4. Enter task name, optional time and repeat, then click Add.
5. Receive browser notifications at task time.
6. Use buttons to switch language, dark mode, view stats, export/import.

## 🛠️ Tech Stack
- HTML5 / CSS3 / JavaScript (ES6)
- LocalStorage for data persistence
- Service Worker (PWA)
- Notification API

## 📦 Installation as PWA
- On Android: Chrome → "Add to Home Screen"
- On iOS: Safari → Share → "Add to Home Screen"
